# F1 Podium Prediction (GUC Milestone 1)

Binary classification: **will this driver finish on the podium?** Features use only information **after qualifying, before the race** (no leakage).

## Repository layout

| Path | Purpose |
|------|---------|
| `data/raw/` | Kaggle Ergast CSVs (not in git) |
| `data/processed/` | Parquet outputs from the pipeline |
| `notebooks/milestone1.ipynb` | **Run-all** notebook for submission |
| `src/` | Reusable pipeline modules imported by the notebook |
| `docs/REPORT_OUTLINE.md` | Skeleton for the PDF report |
| `outputs/figures/` | Plots generated by the notebook |

## Setup (use Wi‑Fi)

```bash
cd "/home/youssef/Documents/Programming/f1-podium-prediction"
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt          # core
pip install -r requirements-ml.txt       # SHAP, LIME, TensorFlow (NN + XAI)
```

### Dataset

1. [Kaggle dataset](https://www.kaggle.com/datasets/rohanrao/formula-1-world-championship-1950-2020)
2. Place all `*.csv` files in `data/raw/`, **or** run:

```bash
chmod +x scripts/download_data.sh
./scripts/download_data.sh
```

## Run the milestone

```bash
source .venv/bin/activate
jupyter notebook notebooks/milestone1.ipynb
```

Use **Run All** after data is present. The notebook saves processed tables and figures under `data/processed/` and `outputs/figures/`.

## Team notes

- Primary metric recommendation: **PR-AUC** (rare positive class); secondary **F1** at validation-chosen threshold.
- Temporal split: train ≤ 2019, validation 2020–2021, test ≥ 2022.
- XAI: feature importance ≠ causation — state that explicitly in the report.
